### 3. TASK-CRE-63 – Property Interest Rate Extraction & Normalization Pipeline

**Technologies:** Python, PostgreSQL, PostGIS, SQLAlchemy, Shapely, Docker, pytest

[View on GitHub](https://github.com/azmeraa/TASK-CRE-63)

A Python-based data engineering project for extracting, validating, normalizing, and staging residential property interest rate records associated with German valuation committees.

Key features:
- Extracts structured records from CSV input.
- Validates required fields, reference years, and source information.
- Normalizes percentage interest rates into decimal fractions.
- Generates stable SHA-256 record identifiers.
- Uses PostgreSQL upserts for duplicate prevention and idempotent loading.
- Implements spatial WKT geometry validation using Shapely and EPSG:25832 enforcement.
- Restricts database writes to a designated staging table.
- Uses Docker Compose for reproducible local execution.
- Includes automated pytest coverage, with 19 tests passing.

*The supplied sample records are synthetic illustrative data, not official German property valuation benchmarks. Shared production database integration has not been established.*
